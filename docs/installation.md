# Installing inksane

Setting up inksane is incredibly easy and requires just a few minutes of work to get a basic editor up and running.

First you need to install inksane with the package manager of your choice. We will be using pnpm, but you can also use npm, yarn or bun.

```sh
pnpm install @inksane/core
```

This installs inksane's core package & all necessary dependencies into your project. Now you're ready to touch some code.
