The `list` extension renders bullet and ordered lists. It adds commands to toggle lists, convert
their type, and nest or unnest items.

## Setup

Import `ListExtension` and pass it through the editor's `extensions` option. Create the mount
element before this code runs:

```ts
import { Editor } from "@inksane/core";
import { ListExtension } from "@inksane/core/extensions/list";

const editor = new Editor({
  element: document.getElementById("editor")!,
  extensions: [ListExtension],
});
```

`ListExtension` handles both bullet and ordered lists. It is included in [BaseKit](/kits/base-kit). Disable both with `BaseKit({ list: false })`.

## What it adds

- Hides the `ListMark` of every `ListItem` and replaces it with a widget: `•` for bullet lists, and
  the computed number for ordered lists.
- Converts pasted `<ul>` and `<ol>` elements to `-` and `1.` lines. The `start` attribute of an
  ordered list is preserved, and multi-line items are indented to line up under the marker.
- Handles multi-line selections and nested lists in its commands.
- Binds Tab and Shift+Tab to nest and unnest list items when the selection is inside a list.

The rendered marker is not the source text. The document keeps the Markdown marker, and the list
extension renders the bullet or number in its place.

Ordered numbers are computed from the list itself: the first item sets the starting number, following
items count up, and a block separated by a blank line restarts at its own marker.

## Commands

| Command                       | Description                                              |
| ----------------------------- | -------------------------------------------------------- |
| `toggleBulletList({ pos? })`  | Adds or removes bullet markers on the selected lines.    |
| `toggleOrderedList({ pos? })` | Adds or removes ordered markers on the selected lines.   |
| `toggleListType({ pos? })`    | Converts selected list items between bullet and ordered. |
| `sinkListItem({ pos? })`      | Indents selected list items one level.                   |
| `liftListItem({ pos? })`      | Outdents selected list items one level.                  |

All commands accept an optional `pos` as a number or a `{ from, to }` range. Without it, they use the
current selection. A multi-line selection applies the command to every selected line.

`toggleBulletList` and `toggleOrderedList` remove markers only when every selected line already has
that plain list type. Otherwise they add or convert markers. Converting a task item to a plain list
item removes its checkbox. Toggling a bullet list on an ordered item replaces the marker instead of
stacking them. The spacing after the marker is kept, so an indented code block inside a list item
stays a code block.

`toggleListType` converts only list items and keeps their text, including task checkboxes. The first
selected item decides the target type. It also adjusts the indentation of nested items so the list
keeps its structure. Lists inside blockquotes convert in place and keep their quote prefix.
List-like text inside code blocks is ignored.

`sinkListItem` indents each selected item under its previous sibling. `liftListItem` moves each
selected item up one level. Nested content moves with its item. The first item in a list cannot sink,
and a top-level item cannot lift. Indentation keeps outer blockquote prefixes in place and counts
tabs by their column width.

```js
editor.commands.toggleBulletList();
editor.commands.toggleListType();
editor.commands.sinkListItem();

editor.chain().toggleOrderedList().focus().run();
```

Tab and Shift+Tab do the same when the selection is inside a list. Outside a list they indent and
dedent lines with spaces. See [keybindings](/extensions/features/keybindings#indentation).

## Styling

```css
[data-inksane-editor-content] {
  .inksane-list-marker {
    display: inline-block;
    color: #999;
    padding-right: 6px;
    user-select: none;
  }

  .inksane-list-marker--ordered {
    min-width: 1.75em;
    text-align: right;
  }
}
```

`.inksane-list-marker--bullet` is available on bullet markers if you want to target them separately.
