The `superscript` extension renders `^text^` as superscript text. It adds a command to toggle the
formatting around the selection or at the cursor.

## Setup

Import `SuperscriptExtension` and register it with the editor:

```ts
import { Editor } from "@inksane/core";
import { SuperscriptExtension } from "@inksane/core/extensions/superscript";

const editor = new Editor({
  element: document.getElementById("editor")!,
  extensions: [SuperscriptExtension],
});
```

This extension is opt-in and is not included in [BaseKit](/kits/base-kit).

## What it adds

- Parses paired `^` markers and hides them while the text is not selected.
- Converts pasted `<sup>` elements to `^text^`.
- Registers `toggleSuperscript`.

The editor keeps the markers in its Markdown source. Escaped markers and markers inside code remain
literal text.

## Command

`toggleSuperscript({ pos? })` toggles superscript around the current selection. At a cursor, it
inserts `^^` and places the cursor between the markers. `pos` can be a number or a `{ from, to }`
range. Without `pos`, the command uses the current selection.

```js
editor.commands.toggleSuperscript();

editor
  .chain()
  .toggleSuperscript({ pos: { from: 0, to: 5 } })
  .focus()
  .run();
```

Use `editor.isActive("superscript")` to check whether the selection is superscript.

## Styling

Add a rule for the `.inksane-mark-superscript` class:

```css
[data-inksane-editor-content] .inksane-mark-superscript {
  vertical-align: super;
  font-size: smaller;
}
```
